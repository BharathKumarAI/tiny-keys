# Tiny Keys

A calm learning game for toddlers: letters, counting, colors, shapes, animals with real sounds,
everyday routines, fruits, songs and a piano. Open it once, then add it to your home screen;
after that it works without internet.

Play: https://bharathkumarai.github.io/tiny-keys/

Credits: animal sounds from Wikimedia Commons (authors and licenses listed on the start screen);
video clips from Pexels (Pexels License).
